# SFJM Boundary — Órulo Integration

## Authority model

```text
ORULO PROJECT MAIN = project/product/integration truth
STOPJUNIORMODE = SFJM protocol authority
SFJM WORKSPACE = derived visualization / continuity consumer
ECOSYSTEM PROJECT = portfolio/search governance context when explicitly adopted
ORULO = external API/provider authority for entitlement, contract and source data
```

## Invariants

- Workspace may consume and render project state; it does not create or approve project state.
- Órulo documentation proves interface semantics, not that this project has a given commercial entitlement.
- Real OAuth credentials never belong in Git.
- `oruloEndUserAuth` restricted data is treated as real-time-only unless an explicit Órulo agreement says otherwise.
- No production deployment, public catalogue, database persistence or indexation follows automatically from successful API access.
- No cross-project authorization propagates into this repository.
